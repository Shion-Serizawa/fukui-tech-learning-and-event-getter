# 02. 機能マップ

利用者から見た機能の一覧。「どの機能の話か」を指すときは、ここの ID と呼び名を使う。

## 一覧

| ID   | 呼び名   | 利用者       | 入口                              | 公開範囲                             | 実装の場所                                   | 要件         |
| ---- | -------- | ------------ | --------------------------------- | ------------------------------------ | -------------------------------------------- | ------------ |
| F-01 | 公開一覧 | 本人・閲覧者 | `GET /`（Pages）                  | 一般公開                             | `web/functions/index.ts` → `src/web/`        | WEB-*        |
| F-02 | RSS      | 本人・閲覧者 | `GET /feed.xml`（Pages）          | 一般公開                             | `web/functions/feed.xml.ts` → `src/feed/`    | RSS-*        |
| F-03 | 収集     | （自動）     | Cron 毎時17分（Worker）           | —                                    | `src/worker.ts` → `src/collector/`           | COL-_, STO-_ |
| F-04 | 健全性   | 本人         | Discord への通知、F-01 のフッター | 通知は本人の Discord、フッターは公開 | `src/domain/`（判定）、`src/notify/`（送信） | HLT-*        |

公開面は Pages の F-01 と F-02 の2つだけ。**Worker は HTTP で何も公開しない**（`workers_dev: false`、`fetch` は常に 404）。公開面に connpass への問い合わせを中継する経路は存在しない（C-06）。

## 画面とその中の呼び名

### F-01 公開一覧

```
+----------------------------------------------------------+
| ヘッダー   「北陸ITイベント」(h1) + 一行の説明           |
+----------------------------------------------------------+
| 福井の節          (h2「福井」)                            |
|   イベントカード  (h3 タイトル = connpass へのリンク)     |
|     日時 / 場所 / [県名バッジ] 参加者数/定員 #ハッシュタグ |
| 石川・富山の節    (h2「石川・富山」)                      |
|   イベントカード ...                                      |
| 終了の節          (h2「終了したイベント」)                |
|   イベントカード + [終了] 表示                            |
+----------------------------------------------------------+
| フッター   「最終収集: YYYY-MM-DD HH:MM」+ 提供元 connpass |
+----------------------------------------------------------+
```

| 呼び名         | 指すもの                                                            |
| -------------- | ------------------------------------------------------------------- |
| 節             | 「福井」「石川・富山」「終了したイベント」の3つの h2 区画           |
| イベントカード | 1件分の枠。タイトル・日時・場所・県名バッジ・参加者数・ハッシュタグ |
| 県名バッジ     | 「福井」「石川」「富山」の文字。色だけに頼らない                    |
| 終了表示       | 終了の節のカードに付く「終了」の文字                                |
| 最終収集日時   | フッターに出す、最後に**成功した**収集回の終了時刻                  |
| 空状態         | 3つの節すべてが0件のときの表示（WEB-08）                            |
| エラー状態     | D1 を読めなかったときの表示（WEB-11）                               |

画面の状態の遷移は [03-behavior.md「公開一覧の表示状態」](03-behavior.md#公開一覧の表示状態) にある。

### F-02 RSS

| 呼び名       | 指すもの                                   |
| ------------ | ------------------------------------------ |
| フィード     | RSS 2.0 の文書全体                         |
| イベント項目 | これから開催されるイベント1件分の `<item>` |

### F-03 収集

| 呼び名          | 指すもの                                                                              |
| --------------- | ------------------------------------------------------------------------------------- |
| 収集回          | Cron の1回の起動で行う一連の取得と保存。`collection_runs` の1行に対応する             |
| 成功回 / 失敗回 | 収集回の結果。失敗回には失敗の種別が付く（COL-07）                                    |
| 最新の成功回    | `status = 'success'` のうち `finished_at` が最大のもの。一覧と RSS に何を出すかの基準 |

### F-04 健全性

| 呼び名              | 指すもの                                                                                |
| ------------------- | --------------------------------------------------------------------------------------- |
| 停止中              | 最新の成功回から3時間を超えて成功回がない状態（HLT-01）                                 |
| 停止通知 / 復旧通知 | 停止中に入ったとき / 停止中から成功回で抜けたときに Discord へ送る1通（HLT-02, HLT-03） |

## 利用者の流れ

```
                    [本人]
        +-------------+-------------+
        v                           v
 経路A: 見に行く (F-01)       経路B: 届く (F-02)
 一覧を上から見る             RSS リーダーで新着を受け取る
        +-------------+-------------+
                      v
         タイトルをクリック → connpass のイベントページ（申込みは connpass で）
```

- 経路A は探索コスト（M-01）、経路B は機会損失（M-02）に対応する
- 経路A には分岐も入力もない。操作は縦スクロールとリンクのクリックだけなので、**並び順と節の区切りがそのまま使い勝手になる**
- 経路B は本人の操作を起点としない。だから見逃しへの対策になる
- 収集の停止には Discord の停止通知で気づく。公開ページのフッターの日付でも分かる
